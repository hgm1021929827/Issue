# 一、介紹

第七階段把專案議題分到獨立 tab，但開啟仍是 dialog，空間不夠。本階段改成與正式議題「待辦」類似的主從切分：看列表同時編輯。

# 二、目標

1. 點專案議題或新增時，不跳出 dialog。
2. 列表與表單可同時看見。
3. 跳轉高亮與追蹤定位仍可用。

# 三、定位

| 欄位 | 說明 |
|------|------|
| 需求類型 | ① Web（UI only） |
| 不在範圍 | Excel、獨立路由、髒資料未存警告 |

# 四、功能需求

### PS-F01：左右切分開啟

| 項目 | 需求 |
|------|------|
| 優先級 | Must |
| MVP | 是 |
| 流程 | 議題 tab 左側列表。點一列，右側顯示該筆表單。按「新增專案議題」，右側為空白表單（項次／標題必填等與現況相同）。 |
| 限制 | 不用 dialog 承載此表單。 |
| 驗收 | 點列或新增都沒有專案議題編輯 dialog；左列右表同時在。 |

### PS-F02：空狀態、儲存、取消

| 項目 | 需求 |
|------|------|
| 優先級 | Must |
| MVP | 是 |
| 流程 | 未選時右側提示選擇或新增。儲存成功右側仍為該筆。取消清空右側。刪正在編的那筆後右側回到空狀態。 |
| 驗收 | 上述三種狀態正確。 |

### PS-F03：跳轉

| 項目 | 需求 |
|------|------|
| 優先級 | Must |
| MVP | 是 |
| 流程 | `?item=` 開議題 tab、左列高亮、右側為該筆；可再高亮項次追蹤。 |
| 驗收 | 不再依賴 dialog 打開。 |
