# 三、流程

- `tab === "items"`：`project-item-workspace` 兩欄。
- 點列 → `openEdit`（`showItemForm`＋`editingId`）；高亮該列。
- 新增 → `openCreateItem`（`editingId` null）。
- 未 `showItemForm`：右側「請選擇左側專案議題，或按新增。」
- 儲存：既有 POST／PUT；成功後以回傳列表定位該筆並保持右側開啟（新增則選新 id）。
- 取消：`closeItemForm`。
- 刪正在編的項次：刪除成功後 `closeItemForm`。
- `?item=`：議題 tab＋`openEdit`＋捲動左列；項次追蹤 `highlightId` 仍傳入右側 `TrackTodoList`。
- 項次追蹤區塊不包在項次 `<form>` 內。
