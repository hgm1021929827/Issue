# 第八階段－專案議題左右切分－QA 測試案例

**角色：** QA  
**日期：** 2026-09-04  
**依據：** [系統設計書](../系統設計/第八階段－專案議題左右切分－系統設計書.md) v1.0  

本輪無新 API。

| 案例 | 步驟 | 預期 |
|------|------|------|
| 01 未選 | 開議題 tab、未點列 | 右側「請選擇左側專案議題，或按新增。」；無編輯 dialog |
| 02 點列 | 點一筆 | 右側表單為該筆；沒有 `dialog` |
| 03 新增 | 新增專案議題 | 右側空白表單標題「新增專案議題」 |
| 04 儲存編輯 | 改標題儲存 | 列表更新；右側仍開該筆 |
| 05 儲存新增 | 填項次標題儲存 | 列表多一筆；右側變編輯且可出現追蹤區塊 |
| 06 取消 | 取消 | 右側回到空狀態 |
| 07 跳轉 | `?item=` | 議題 tab、左高亮、右為該筆 |
| 08 刪除確認 | 刪一筆 | 仍為確認 dialog；若刪正在編的，右側清空 |
| 09 GET 專案 | `/projects/{id}` | 契約不變 |
