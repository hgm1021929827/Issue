# 開發階段總覽

本文件是專案開發歷程的唯一階段索引。階段依全專案時間軸編號；新一輪改善必須建立下一階段，不覆寫已結束階段的正式文件。第四階段進行中時，使用者要求覆蓋該階段尚未實作的 Excel 正式文件，改為成員與廠商；Excel 原稿改放該階段歷史資料。2026-09-04 使用者另交《專案工作項次、專案議題與工時結構需求補充文件》，舊 Excel 設計不得直接實作。同日使用者選擇先做「需要追蹤的 TODO」，插入為第五階段。2026-09-05 後續階段遞補缺號的第六階段；工作項次改列第十二階段。同日開立並完成第十二階段。同日使用者指示開立第十三階段「正式議題 Excel 匯入」。2026-09-09 使用者指示開立第十四階段「議題列表小分類篩選」。同日再開立第十五階段「議題列表廠商與搜尋」。
