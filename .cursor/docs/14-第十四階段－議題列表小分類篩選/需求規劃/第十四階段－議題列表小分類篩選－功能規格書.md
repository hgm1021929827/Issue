# 第十四階段－議題列表小分類篩選－功能規格書

**角色：** PM  
**版本：** v1.0  
**日期：** 2026-09-09  
**需求類型：** ① Web 應用（API query 增量，無 Database Schema）  
**來源：** 使用者「議題上面的篩選改為議題小分類」

已跳過討論文件（F-01）。假設：只改 `/issues` 列表 Chip；首頁「正式議題」分頁與專案列表仍用大分類；未填小分類的議題只出現在「全部」，不加「未分類」Chip。

### IL-F01

| 項目 | 需求 |
|------|------|
| 目的 | 議題列表用小分類篩選，對齊處理中／加簽／已結案等實際狀態 |
| 優先級 | Must |
| MVP | 是 |
| 流程 | `/issues` 標題下方 Chip 為「全部」加大分類「議題」（若無則「議題分類」）底下的小分類，依排序。點 Chip 只顯示該小分類的正式議題。 |
| 限制 | 不改首頁、專案列表。不新建分類。不強制每筆議題都有小分類。 |
| 驗收 | Chip 名稱為小分類；選「處理中」只見該類；「全部」仍見未分類與其他大分類下的議題。 |

**本功能無新 Table。第七章 Database 項目：沿用既有 `sub_category`／`issue.sub_category_id`。**
