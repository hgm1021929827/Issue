# 一～二

`IssueListPage` 在小分類 Chip 下加廠商 `AppSelect` 與搜尋列。`GET /issues` 新增 `clientCompanyId`、`q`。無 Schema。首頁不改。

# 三、流程

- 廠商選項：`GET /client-companies`；第一項「全部廠商」。開啟下拉後，選單頂端有搜尋框，依名稱過濾選項（前端本地，不分大小寫）。
- 搜尋：trim 後比對 `issueNo`、`title`（ToLower Contains）。
- 與 `subCategoryId`／既有 `majorCategoryId` AND。
- 無符合：文案「沒有符合的議題。」；完全沒資料仍「尚無議題」＋立即新增。
- 外觀沿用既有 input／`AppSelect`／`.btn`。

# 四、API

| 方法 | 路徑 | query | 說明 |
|------|------|-------|------|
| GET | `/issues` | `majorCategoryId?`、`subCategoryId?`、`clientCompanyId?`、`q?` | 皆可選，同時為 AND。無效 id 或無命中回空列表 |

# 五～六

`api.issues` 物件參數加 `clientCompanyId`、`q`。廠商下拉不用 `VendorSelect`（避免新增廠商鈕）。
