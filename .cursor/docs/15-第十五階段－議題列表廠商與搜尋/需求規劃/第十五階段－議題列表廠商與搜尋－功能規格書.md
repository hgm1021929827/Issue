# 第十五階段－議題列表廠商與搜尋－功能規格書

**角色：** PM  
**版本：** v1.0  
**日期：** 2026-09-09  
**需求類型：** ① Web 應用（API query 增量，無 Database Schema）  
**來源：** 使用者「我想在這邊加一個篩選廠商的下拉式選單和搜尋框」（議題列表 `/issues`）

已跳過討論文件（F-01）。假設：只改 `/issues`；與第十四階段小分類 Chip 併用（AND）；搜尋編號與標題；廠商下拉不含「新增廠商」。

### IL-F02

| 項目 | 需求 |
|------|------|
| 目的 | 在議題列表用廠商與關鍵字縮小清單 |
| 優先級 | Must |
| MVP | 是 |
| 流程 | Chip 下方：廠商下拉（全部廠商＋客戶公司；開啟後選單內可搜尋廠商名稱）、搜尋框、搜尋鈕。下拉立刻篩選。輸入後按 Enter 或「搜尋」依編號或標題（不分大小寫、含部分字）篩選。可與小分類同時成立。 |
| 限制 | 不改首頁、專案列表。不下拉新增廠商。無廠商的議題只在「全部廠商」。空白關鍵字等於不搜尋。 |
| 驗收 | 選一廠商只見該廠商；搜尋標題或編號只見命中列；與 Chip 可疊加；無符合時提示而不是「尚無議題」。 |

**本功能無新 Table。沿用 `issue.client_company_id`。**
