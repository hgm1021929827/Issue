# 第五階段－需要追蹤的 TODO－文件導覽

| 項目 | 說明 |
|---|---|
| 階段目標 | 需要追蹤的 TODO、追蹤對象選擇、首頁追蹤項目 |
| 需求類型 | ① Web 應用（含 UI／API，將有 Database） |
| 技術棧 | 沿用第一階段：React（Vite）、ASP.NET Core 9、MySQL |
| 狀態 | 已結束（2026-09-05 使用者確認測試完成） |
| 與第一階段關係 | 不覆寫第一階段正式文件；一般 TODO 契約維持第一階段；本輪增量接上追蹤 TODO |
| 與第二階段關係 | 新畫面與元件必須對齊 [視覺設計規格書](../02-第二階段－粉彩視覺風格/需求規劃/第二階段－粉彩視覺風格－視覺設計規格書.md) |
| 與第三階段關係 | 不覆寫第三階段正式文件；追蹤是否掛專案／專案議題交 PM 討論 |
| 與第四階段關係 | 不覆寫第四階段正式文件；沿用成員／窗口兩套主檔與廠商綁定 |
| 原始需求 | [個人工作追蹤網頁需求修正與新增內容.pdf](../../../docs/個人工作追蹤網頁需求修正與新增內容.pdf)（不複製、不改該檔）第二章、第十五章 |

本階段範圍只要追蹤 TODO、追蹤對象選擇、首頁追蹤項目。工作項次／工時／Excel、加簽、預約連線、臨時工作、登入不在本輪。範圍凍結見 [階段開立紀錄](流程管理/第五階段－需要追蹤的 TODO－階段開立紀錄.md)。
