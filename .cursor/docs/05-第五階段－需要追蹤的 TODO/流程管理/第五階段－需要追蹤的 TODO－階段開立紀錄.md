- 第四階段已交付成員／廠商（QA 結案）。追蹤本輪才做；第一、三、四階段正式文件不覆寫。
- 第二階段粉彩視覺仍進行中（規格已確認、頁面已套用）；本階段不結案第二階段。

## 二、範圍凍結

| 本階段做 | 本階段不做（留給之後新階段） |
|----------|------------------------------|
| 追蹤 TODO（來源 §2.1） | 工作項次、工時、Excel 再次匯入（第十二階段） |
| 追蹤對象選擇（來源 §2.2） | 加簽狀態保存與恢復、加簽大分類 |
| 首頁追蹤項目（來源 §2.3） | 預約連線 CRUD／清單／行事曆 |
| | 臨時工作、登入／權限 |

欄位細節、掛在哪種工作、與第一階段「一般 TODO」如何區隔：交 PM《規格書討論文件》勾選，WFM 不定案。

已知約束（前階段已確認、本輪不得推翻為登入系統）：

- 第一階段 Q3＝A：單人、無登入；成員與客戶是**通訊錄資料**，不是帳號。
- 第四階段 Q1＝A：公司成員與客戶窗口兩套主檔。
- 第四階段 Q2＝B、Q3＝C、Q4＝A：專案廠商必填、正式議題廠商必填、專案議題廠商跟隨專案。
- 來源 2.2：內部成員＝公司成員清單；客戶窗口＝該議題或專案所屬客戶公司的窗口；未設廠商時選客戶窗口要提示。

已知缺口（PM 必須先討論，不可因總覽有標題就跳過）：

- 追蹤 TODO 可掛在哪些工作（正式議題／專案／專案議題）
- 與既有一般 TODO 的關係（獨立實體或同一棵樹加標記）
- 是否多層、排序、完成規則是否沿用一般 TODO
- 第四階段刪除檢查尚未含追蹤實體；本輪成員／公司／窗口刪除要不要加占用檢查
- 廠商已必填後，「未設廠商」提示還有沒有實際路徑
- 首頁列出未完成或含已完成、跳轉落點
