# 三、流程

- 路由：`/issues` 清單；既有 `/issues/new`、`/issues/:id` 維持；順序清單先於 `:id`。
- 導覽：首頁、議題、專案、成員、分類設定。新增入口在清單頁。

- 刪除議題：`navigate("/issues")`。
