# 第十階段－正式議題獨立列表頁－QA 測試案例

**依據：** [系統設計書](../系統設計/第十階段－正式議題獨立列表頁－系統設計書.md) v1.0  

| 案例 | 預期 |
|------|------|
| 01 導覽 | 有「議題」，無頂欄「新增議題」 |
| 02 `/issues` | 標題、分類 Chip、新增、列點進詳情 |
| 03 `/issues/new` | 仍可新增；NavLink 議題為作用中 |
| 04 首頁 | 無完整議題清單；有追蹤與月曆 |
| 05 預計項目 | 下拉選議題後點月曆可排入；可移除 |
| 06 刪除議題 | 回到 `/issues` |
