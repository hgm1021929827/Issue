## Q-12-01 匯入決策未驗證「恰好覆蓋本次 notFound」

**問題描述：** `POST /projects/{id}/import-decisions` 在 `decisions: []` 時回 200 `{ applied: true }`，未比對本次匯入結果的 `notFound`。系統設計書 §4.5：必須恰好覆蓋本次 `notFound` 每一筆，缺漏 → 400「請為每筆未找到資料選擇保留或刪除」。

**問題類型：** 實作類  

**重現步驟：**
1. 對任一存在的專案（例：`id=1`）POST `/projects/1/import-decisions`，body `{ "decisions": [] }`。
2. 觀察 HTTP 狀態與 `data`。

**預期結果：** 若本次匯入有未找到列，400 且文案為「請為每筆未找到資料選擇保留或刪除」。  
**實際結果：** HTTP 200，`applied: true`。  
**影響程度：** Medium（前端結果頁有擋未選完；直接打 API 或重整後重送可略過決策）  
**分派對象：** RD  
**看板 CC：** SA  
**狀態：** 階段結案延後
