## B. 檔名對專案

- [x] B-01 檔名如 `P-xxxx 其餘名稱.xlsx` 且代號已存在 → 匯入該專案（不論目前開哪筆詳情）
- [x] B-02 代號不存在 → 進新增專案頁，代號與建議名稱已填
- [x] B-03 新增頁補齊廠商等必填後存檔 → 自動以同一檔續匯，進結果頁
- [x] B-04 取消新增或存檔失敗 → 沒有新工作項次
- [x] B-05 檔名解析不出代號 → 橫幅失敗，不開新增頁
