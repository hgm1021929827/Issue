# 第十二階段－專案工作項次與工時－文件導覽

| 項目 | 說明 |
|---|---|
| 階段目標 | 專案工作項次、工時紀錄、專案 Excel 匯入與再次匯入差異 |
| 需求類型 | ① Web 應用（含 UI／API，將有 Database） |
| 技術棧 | 沿用第一階段：React（Vite）、ASP.NET Core 9、MySQL |
| 狀態 | 已結案（使用者確認測試完成） |
| 與前階段關係 | 不覆寫第一～十一階段正式文件；專案／專案議題／成員主檔沿用；本輪增量接上工作項次、工時與專案匯入 |
| 與第二階段關係 | 新畫面與元件必須對齊 [視覺設計規格書](../02-第二階段－粉彩視覺風格/需求規劃/第二階段－粉彩視覺風格－視覺設計規格書.md) |
| 準據 | [需求補充文件](../../../docs/專案工作項次、專案議題與工時結構需求補充文件.docx)；衝突時不以第四階段歷史 Excel 原稿為準 |
| 實務對照 | [Template/](../../../Template/) 專案 `P-*.xlsx` 的「工作項目」「議題單」；`議題匯入範本.xls` 不在本輪 |

本階段範圍只要工作項次、工時、專案 Excel（工作項目／議題單）與再次匯入差異。正式議題匯入、加簽、預約連線、臨時工作、登入不在本輪。範圍凍結見 [階段開立紀錄](流程管理/第十二階段－專案工作項次與工時－階段開立紀錄.md)。
