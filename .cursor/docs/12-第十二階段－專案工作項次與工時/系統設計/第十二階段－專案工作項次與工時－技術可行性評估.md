**日期：** 2026-09-05  
**依據：** 規格書 §8.1／8.2／8.3／8.4／8.5 待評估項、系統設計草擬 API／UI

## 結論

**可行。** 沿用 React SPA、ASP.NET Core 9、MySQL、粉彩 token、`AppDialog`／`AppSelect`／`AppDateField`、專案議題左右切分與 `?item=` 高亮。Excel 在後端用 **ClosedXML** 讀 `.xlsx`。先建專案再續匯：**前端記憶體保住 `File`**，不建伺服器暫存檔。

本輪無須於 Spike 交付正式功能程式。

## 評估項目

| 項目 | 結果 | 說明 |
|------|------|------|
| ClosedXML 讀表／日期序號 | 可行 | 舊稿 Spike 仍適用：`TryGetWorksheet`、名稱 trim 忽略大小寫；日期用 `TryGetValue<DateTime>`。不執行巨集。上傳 `multipart`、建議 5 MiB。 |
| 表頭別名 | 可行 | 第一個非空列當表頭；正規化後對別名。工作項目：工作代號／工作說明／計畫人天／負責人員／預計開始日／預計完成日／備註。議題單：項次／需求說明／解決方案／處理人員／預計完成日／備註。其餘欄忽略。 |
| 檔名解析 | 可行 | 去路徑與 `.xlsx`；第一個空白前＝`projectCode`；其餘＝建議名稱。無空白則整段當代號、名稱空。對不到代號 → 400，不開新增頁。 |
| 先新增專案再續匯同一檔 | 可行 | **前端持有 `File` + `currentUserMemberId`**（React state／模組變數，隨 `navigate('/projects/new', { state })`）。新增成功後立刻 `POST /projects/{id}/imports`。重整或關頁則 state 沒了，提示重選檔。不採用伺服器 token 暫存（單人、少收益、要清 TTL）。 |
| 匯入結果重整 | 可行 | 結果用 `navigate(..., { state })`。重整後無 state：提示「請重匯」。未找到決策 `POST` 一次送出；未決策就離開則項次／議題已 upsert、未找到列維持原狀，下次再匯會再列。不建匯入歷程表。 |
| 備註工時正則 | 可行 | 逐行：可選年、`M/D` 或 `M-D`、可選多餘空白與負號、數字（可小數）+ `H`/`h`。對得上 `6/18 - 4.5H`、`06/05  -1.5H`、`3/16-2h`。對不上（如 `1/20  表單討論7張  6H`）→ 該行列 `unparseableRemark`。省略年用伺服器當地年。可解析且網頁缺該日則寫入。 |
| 三 tab＋左右切分 | 可行 | `ProjectPage` 現有兩 tab 加 `"workItems"`；工作區重用 `.project-item-workspace`。`?workItem=` 比照 `?item=`。 |
| 工時小表 | 可行 | 日期＋小時＋備註列；同日 409。 |
| 首頁嵌套項次＋月曆 | 可行 | `HomePage` 專案群組再 `GET work-items`；`MonthCalendar` 加 `source=workItem`。格內已可捲。 |
| 項次追蹤 TODO | 可行 | 第四條 nested 路徑；`workType=workItem`；跳轉 `?workItem=&trackTodo=`。 |
| 篩選包含／All | 可行 | 字串 Contains 中文名或英文名／全等 All，忽略大小寫。 |
