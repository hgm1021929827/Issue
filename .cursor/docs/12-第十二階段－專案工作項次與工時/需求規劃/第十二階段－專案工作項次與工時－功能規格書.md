# 一、專案介紹

本階段讓專案底下除了既有**專案議題**之外，平行新增**工作項次**，並讓項次與議題各自記錄**日期工時**。工作項次主資料以專案 Excel「工作項目」為準；專案議題可繼續手維護，也可從「議題單」匯入更新。

再次匯入時：相同識別更新 Excel 管理欄位；新列新增；本次未找到不自動刪，由使用者在結果頁選保留（明顯標示）或刪除。Excel 備註裡的工時只拿來逐日比對，不覆寫網頁工時。

不做正式議題匯入、加簽、預約、登入。

# 二、專案目標

1. 專案詳情第三個 tab「工作項次」：左清單右詳情；可看管理欄位（唯讀）、紀錄工時、標記完成、掛追蹤 TODO。不能在網頁手新增工作項次。
2. 工作項次與專案議題各自 0～多筆工時（日期、工時、備註）；同日最多一筆；只累計自己的工時，不算專案總工時。
3. 實際開始＝該筆最早工時日（無則空）。可標記完成／取消完成；無工時也可完成，此時實際結束可空；有工時且標記完成時實際結束＝最後一筆工時日。
4. 一次匯入一個 `.xlsx`。依檔名對專案代號：已存在則匯入該專案；不存在則先開新增專案頁帶入代號／名稱，補齊必填後以同一檔繼續匯入。
5. 匯入時下拉選「目前使用者」（公司成員，記住上次選擇），依負責人員／處理人篩選；`All` 或儲存格包含該成員中文名或英文名即通過。
6. 只讀「工作項目」「議題單」。工作代號空白列不匯入。議題單匯核心欄，項次鎖定。
7. 匯入結果頁處理未找到列的保留／刪除；保留者在詳情明顯標示，日後 Excel 再出現則恢復正常。
8. 首頁「專案」tab 嵌套工作項次；月曆到期日視角加上有預計完成日的工作項次。工作項次可掛追蹤 TODO，規則比照專案議題。

# 四、功能需求

### WI-F01：專案頁工作項次 tab（左右切分）

| 項目 | 需求 |
|------|------|
| 功能目的 | 在專案詳情查看已匯入或保留的工作項次 |
| 優先級 | Must |
| 是否本輪 MVP | 是 |
| 使用流程 | 已儲存專案詳情除「專案內容」「專案議題」外，加 tab「工作項次」。版面比照專案議題：左清單、右詳情。清單顯示工作代號、工作說明、負責人員、預計完成日；本次匯入未找到而選擇保留者須**明顯區別**（標籤或同等可辨識方式，不鎖死顏色）。右側顯示管理欄位（唯讀，見 WI-F02）、目前工時合計、實際起迄、標記完成、工時列表（WI-F03）、追蹤 TODO（WI-F06）。跳轉 `?workItem=` 時打開此 tab 並選中該筆、捲動高亮（比照 `?item=`）。新增專案尚未存檔時不出現此 tab。 |
| 功能限制 | **不可**在網頁新增工作項次。不可改掛到其他專案。不可依工作代號畫出樹狀父子。清單排序穩定即可，**不得**依 `3.1.1` 推階層。 |
| 注意事項 | 無項次時顯示空狀態，並提示從專案清單或本頁「匯入 Excel」匯入。刪專案時連同工作項次、其工時、其追蹤 TODO 一併刪。 |
| 驗收條件 | 匯入後 tab 看得到項次；點左列右詳情對應；`?workItem=` 落在正確 tab 與列；畫面沒有「新增工作項次」；保留列與一般列可分辨。 |

### WI-F02：工作項次管理欄位唯讀

| 項目 | 需求 |
|------|------|
| 功能目的 | Excel 為項次主資料來源，網頁不手改 |
| 優先級 | Must |
| 是否本輪 MVP | 是 |
| 使用流程 | 右側以唯讀展示：工作代號、工作說明、計畫人天、負責人員、預計開始日、預計完成日。再次匯入相同識別時，以上欄位直接改成本次 Excel 值。備註欄用於解析 Excel 工時，不把整段備註當網頁工時備註覆寫。 |
| 功能限制 | 以上欄位沒有編輯儲存。不可用工作項目表的「項次」欄當識別或可改欄。 |
| 注意事項 | 工作代號即使為 `2.2.1` 只當字串識別。 |
| 驗收條件 | 詳情無法改工作說明等管理欄位並存檔；再匯入後說明與預計日已更新。 |

### WI-F03：工時紀錄（工作項次與專案議題）

| 項目 | 需求 |
|------|------|
| 功能目的 | 在網頁逐日記自己的工時 |
| 優先級 | Must |
| 是否本輪 MVP | 是 |
| 使用流程 | 工作項次詳情與專案議題詳情各有「紀錄工時」：可新增、修改、刪除。每筆＝日期（必填）、工時（必填、正數、可小數）、備註（可空，使用者自己的說明）。同一項次或同一議題、同一日最多一筆；衝突不可存。列表顯示該筆目前工時＝所有日期工時加總。不計算、不顯示專案總工時。專案本體沒有逐日工時。 |
| 功能限制 | 工時須大於 0。不匯出 Excel。刪項次或議題時其工時一併消失。 |
| 注意事項 | 網頁工時備註不與 Excel 備註文字比對。 |
| 驗收條件 | 項次與議題都能各建一筆工時；同日第二筆不可存；合計正確；專案內容頁沒有專案總工時。 |

### WI-F04：實際起迄與標記完成

| 項目 | 需求 |
|------|------|
| 功能目的 | 用自己的工時推導實際日，並標記是否完成 |
| 優先級 | Must |
| 是否本輪 MVP | 是 |
| 使用流程 | 工作項次與專案議題詳情各有「標記完成／取消完成」（不是改分類）。**實際開始**＝該筆工時最早日；無工時則空；每次工時增刪改後重算。**標記完成**：允許在無工時時標記；有工時時實際結束＝最後一筆工時日；無工時時實際結束為空。取消完成：清空實際結束，不刪工時、不改實際開始。標記後再加工時**不**自動改實際結束。 |
| 功能限制 | 完成標記不是小分類替代。實際日不手填。 |
| 注意事項 | 專案本體本輪不加標記完成。 |
| 驗收條件 | 無工時可標記完成且實際結束為空；有 6/12、6/15 兩筆工時時標記完成則實際結束＝6/15、實際開始＝6/12；取消完成後實際結束清空、工時仍在。 |

### WI-F06：工作項次可掛追蹤 TODO

| 項目 | 需求 |
|------|------|
| 功能目的 | 在項次上追人，規則比照專案議題 |
| 優先級 | Must |
| 是否本輪 MVP | 是 |
| 使用流程 | 工作項次右側有「需要追蹤的 TODO」區塊，欄位與行為沿用第五階段（完成、標題、內容、兩層對象、單層拖曳）。客戶窗口＝**所屬專案**的廠商窗口。刪項次連刪其追蹤。首頁追蹤項目工作類型增加「工作項次」；跳轉進專案詳情工作項次 tab 並定位（`?workItem=`＋`trackTodo=`）。月曆追蹤提醒來源含掛在項次上的追蹤。 |

| 驗收條件 | 項次可新增追蹤並出現在首頁未完成列表；跳轉落到該項次與該筆；刪項次後追蹤消失。 |

### WI-F07：匯入入口、單檔、目前使用者

| 項目 | 需求 |
|------|------|
| 功能目的 | 指定「這次我是誰」並只匯一個檔 |
| 優先級 | Must |
| 是否本輪 MVP | 是 |
| 使用流程 | 專案清單提供「匯入 Excel」。已存專案詳情也可開同一匯入。對話：選 `.xlsx`（一次一個）、下拉公司成員當目前使用者（必選）。下拉預設**上次成功選過的成員**（本機記住即可）；沒有紀錄則請使用者選。送出後走 WI-F08～F14。 |

| 驗收條件 | 選兩個檔無法一次送出；第二次開啟匯入時預設仍是上次那位成員；可改選別人。 |

### WI-F08：依檔名對專案，缺則新增頁補齊再匯入

| 項目 | 需求 |
|------|------|
| 功能目的 | 用檔名對到既有專案，或先建檔再匯 |
| 優先級 | Must |
| 是否本輪 MVP | 是 |
| 使用流程 | 從檔名解析專案代號（實檔形如 `P-20260108-1497 104-中華資安-UOFX客製.xlsx`：空白前為代號，其餘去副檔名當建議名稱）。**已有相同代號**（忽略大小寫）→ 匯入該專案，不看使用者目前開的是哪一筆詳情。**沒有該代號**→ 不寫入工作表，改開新增專案頁，帶入代號與建議名稱；使用者依第三、四階段補齊必填（名稱、分類、廠商等）並存檔。存檔成功後，**自動以同一檔、同一目前使用者繼續匯入**到剛建的專案。取消新增或存檔失敗：本次匯入不寫入任何工作項次／議題。檔名解析不出代號：整批失敗，提示檔名格式，不開新增頁。 |
| 功能限制 | 不一次匯多專案。不依檔名自動建好卻缺廠商的半成品專案。 |
| 注意事項 | 「同一檔繼續匯入」的暫存方式交 Spike（記憶體／暫存）；重整或關閉後檔案沒了應提示重新選擇檔案。 |
| 驗收條件 | 已有代號的檔匯入該專案；新代號會先出現新增專案頁且代號已填；補齊廠商存檔後項次出現在新專案；取消新增則系統沒有新項次。 |

| 項目 | 需求 |

| 優先級 | Must |

| 驗收條件 | 刪掉議題單後匯入失敗且資料不變；只有議題單沒有工作項目有效列則失敗。 |

### WI-F10：負責人員／處理人篩選

| 項目 | 需求 |
|------|------|
| 功能目的 | 只匯與目前使用者相關的列 |
| 優先級 | Must |
| 是否本輪 MVP | 是 |
| 使用流程 | 「工作項目」比對負責人員欄；「議題單」比對處理人員欄。儲存格去前後空白後：等於 `All`（忽略大小寫）→ 通過；否則若包含目前使用者中文名或英文名（忽略大小寫）→ 通過。未通過的列視為本次不存在（補充 §3.1）。 |
| 功能限制 | 英文名空白則只比中文名。短英文名可能誤中（與中文 Contains 同一取捨）。 |
| 注意事項 | 實檔（中華資安）負責人員可寫 Eva／Hill 等英文名。原本因不是目前使用者而未匯入的列，之後改成包含該人，視為新資料新增。 |
| 驗收條件 | 負責人員「蕭維德、李中凱」在目前使用者＝蕭維德時匯入；負責人員「Eva」在該成員英文名＝Eva 時匯入；目前使用者中英文名都不在格內且不是 All 則不匯該列；`All` 會匯入。 |

### WI-F11：工作項次識別與寫入

| 項目 | 需求 |
|------|------|
| 功能目的 | 以專案編號＋工作代號對上同一筆 |
| 優先級 | Must |
| 是否本輪 MVP | 是 |
| 使用流程 | 工作代號必填（trim 後非空）。空白 → 該列異常、不匯入，不用「項次」欄或標題替代。同一專案內工作代號唯一（忽略大小寫）。已有 → 更新管理欄位。沒有 → 新增。不依代號建父子。忽略處理時間(PM/SA/PG/QC) 與工作項目表「項次」欄。 |
| 功能限制 | 同檔第二列撞同一工作代號 → 該列異常。 |

| 驗收條件 | 同一代號再匯是更新不是第二筆；無代號列不進系統並列異常；`2.2.1` 與 `2.2` 是兩筆平鋪。 |

### WI-F12：議題單寫入

| 項目 | 需求 |
|------|------|
| 功能目的 | 議題單 upsert 專案議題 |
| 優先級 | Must |
| 是否本輪 MVP | 是 |
| 使用流程 | 項次必填，同一專案忽略大小寫唯一。已有 → 更新：需求說明→標題、解決方案→內容、處理人員、預計完成日；備註只拿去解析工時比對。沒有 → 新增（分類預設同第三階段新增議題）。項次空白 → 該列異常。網頁可手改標題、內容、分類、處理人、預計日；再匯入有對到的欄就更新。項次不可手改。 |

### WI-F13：備註工時解析與比對（不覆蓋網頁）

| 項目 | 需求 |
|------|------|
| 功能目的 | 把 Excel 備註當來源工時：網頁缺該日則寫入；已有該日只比對不覆蓋 |
| 優先級 | Must |
| 是否本輪 MVP | 是 |
| 使用流程 | 解析「工作項目」「議題單」備註中的逐日工時（補充示例 `6/18 - 4.5H`、實檔 `3/16-2h`）。可多行。可解析且網頁沒有該日 → 新增該日工時（備註留空），並重算實際開始。網頁已有該日 → 不改小時、不改網頁備註。不得刪網頁既有工時。無法解析的行列為差異。其餘比對：Excel 有該日但寫入失敗／被擋；同日小時不同；網頁有該日 Excel 無。 |

# 五、角色權限

單人無登入。任何開得了本機網站的人可操作本階段全部功能。成員下拉是通訊錄，不是帳號。

# 六、功能流程

1. （可選）專案清單按「匯入 Excel」→ 選一個 xlsx、選目前使用者。
2. 解析檔名：有專案則匯入；無則新增專案頁補齊 → 存檔 → 同一檔繼續匯入。
3. 檢查兩張表與篩選；寫入項次／議題管理欄位；備註可解析且網頁缺該日則寫入工時，已有該日只比對。
4. 結果頁處理未找到：保留或刪除。
5. 到專案詳情工作項次／議題 tab 記工時、標記完成、掛追蹤。
6. 首頁與月曆可點進項次；追蹤未完成出現在首頁追蹤 tab。

# 八、UI／UX 需求

視覺對齊第二階段。確認用 `dialog`。

### 8.1 專案頁－工作項次 tab

* **畫面元素：** tab「工作項次」；左清單（代號、說明、標示）；右唯讀管理欄、工時表、完成按鈕、追蹤區塊。
* **使用者操作：** 切 tab、點列、記工時、標記完成、追蹤 CRUD、匯入入口。
* **系統回應：** 右詳情切換；`?workItem=` 高亮。
* **錯誤狀態：** 工時同日重複、驗證失敗。
* **載入狀態：** 無項次空狀態。
* **Spike 狀態：** 待評估（三 tab＋左右切分擁擠度）。

### 8.2 匯入對話

* **畫面元素：** 單檔選擇、成員下拉（預設上次）、送出／取消。
* **使用者操作：** 選檔、選人、送出。
* **系統回應：** 進新增專案或結果頁。
* **錯誤狀態：** 未選人、未選檔、非 xlsx、檔名無代號、缺表。
* **載入狀態：** 解析／上傳中不可重送。
* **Spike 狀態：** 已確認可行方向（後端解析）；檔案在「先建專案再續匯」的暫存待評估。

### 8.3 新增專案頁（匯入帶入）

* **畫面元素：** 既有新增專案表單；代號、名稱預填。
* **使用者操作：** 補廠商等必填、存檔或取消。
* **系統回應：** 成功則續匯；取消則不寫項次。
* **錯誤狀態：** 第四階段既有驗證。
* **載入狀態：** 存檔中。
* **Spike 狀態：** 待評估（帶檔返回／暫存）。

### 8.4 匯入結果頁

* **畫面元素：** 摘要、異常列、工時備註逐行（依儲存格順序；無法解析為文字框＋保留進備註最後一行；每列刪除）、未找到列（每筆保留／刪除）、確認。
* **使用者操作：** 逐行刪除或勾選保留文字、勾選未找到處理、確認、跳轉專案／項次／議題。
* **系統回應：** 刪工時列立即刪網頁該日；確認時把勾選文字接到該筆最後一筆工時備註；保留加標示。
* **錯誤狀態：** 未選完未找到列。
* **載入狀態：** 確認中。
* **Spike 狀態：** 待評估（結果是否暫存、重整提示）。

### 8.5 首頁與月曆增量

* **畫面元素：** 專案群組下工作項次列；月曆到期日多一種項次標記。
* **使用者操作：** 點列／點日曆跳轉。
* **系統回應：** 進工作項次 tab。
* **錯誤狀態：** 項次已刪則開專案並提示。
* **載入狀態：** 與現有首頁一致。
* **Spike 狀態：** 待評估（專案下同時嵌套議題與項次的擁擠）。

### 8.6 工時小表

* **畫面元素：** 日期、小時、備註、增刪改。
* **使用者操作：** 新增一列、改、刪確認。
* **系統回應：** 合計與實際開始更新。
* **錯誤狀態：** 同日重複、小時 ≤0。
* **載入狀態：** 無工時空狀態。
* **Spike 狀態：** 已確認可行（常規表格）。

# 九、非功能需求

* **效能：** 單專案數百列工作項次＋議題的一次匯入，應在個人本機可接受時間完成（目標數十秒內）；結果頁可捲動。
* **安全性：** 無登入；不執行 Excel 巨集；上傳僅 xlsx。
* **維護性：** 工作項次與專案議題規則分開寫清；工時共用同一套。
* **擴充性：** 正式議題匯入、其他工作表留給之後階段。
* **語系：** 繁體中文。
