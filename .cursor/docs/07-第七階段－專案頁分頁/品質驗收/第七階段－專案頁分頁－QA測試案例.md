# 第七階段－專案頁分頁－QA 測試案例

**角色：** QA  
**日期：** 2026-09-04  
**依據：** [系統設計書](../系統設計/第七階段－專案頁分頁－系統設計書.md) v1.0  
**需求類型：** ① Web 應用

本輪無新 API。案例以畫面狀態與既有端點回歸為主。

## TC-01 配置

| 案例 | 步驟 | 預期 |
|------|------|------|
| 01-01 新增專案 | 開 `/projects/new` | 無 tab；單一表單 |
| 01-02 已儲存 | 開 `/projects/{id}` 無 query | 有「專案內容」「專案議題」；預設內容 |
| 01-03 互斥 | 點議題 tab | 看不到專案表單與專案層追蹤；看得到列表 |
| 01-04 筆數 | 列表有 N 筆 | 議題 tab 文案含（N） |
| 01-05 未存表單 | 內容 tab 改名稱後切走再切回 | 名稱仍在、未自動儲存 |

## TC-02 跳轉

| 案例 | 步驟 | 預期 |
|------|------|------|
| 02-01 `?item=` | 開專案議題連結 | 議題 tab；列高亮；dialog 編輯 |
| 02-02 項次＋追蹤 | `item`＋`trackTodo` | 議題 tab；dialog 內高亮追蹤 |
| 02-03 僅專案追蹤 | 只有 `trackTodo` | 內容 tab；專案層追蹤高亮 |
| 02-04 無此項次 | `item` 不存在 | 專案仍開；橫幅「找不到該專案議題」 |

## TC-03 回歸 API

| 案例 | 步驟 | 預期 |
|------|------|------|
| 03-01 GET 專案 | `/projects/{id}` | 200，含 items（契約不變） |
| 03-02 既有單元測試 | `dotnet test` | 全通過 |
