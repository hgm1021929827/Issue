**日期：** 2026-09-04  
**依據：** [系統設計書](../系統設計/第七階段－專案頁分頁－系統設計書.md) 第三、六章

---

> 以下清單由 QA 建立，交由使用者逐項手動驗證。QA 本輪不自行點擊畫面。使用者於 2026-09-05 確認測試完成。

## A. 新增與分頁列

- [x] A-01 `/projects/new` 沒有「專案內容／專案議題」tab
- [x] A-02 儲存新專案後進入詳情，出現兩個 chip tab
- [x] A-03 預設停在「專案內容」，看得到表單與專案層追蹤 TODO
- [x] A-04 「專案議題」tab 顯示目前筆數

## B. 切換

- [x] B-01 點「專案議題」後，專案表單與專案層追蹤消失，議題列表佔主要空間
- [x] B-02 點回「專案內容」，表單回來
- [x] B-03 在內容 tab 改了名稱尚未儲存，切到議題再切回，名稱仍在
- [x] B-04 議題 dialog 開著時切到內容 tab，dialog 不會被強制關掉

## C. 議題操作

- [x] C-01 議題 tab 可新增；dialog 儲存後列表更新、筆數更新
- [x] C-02 點列開啟編輯 dialog；項次追蹤 TODO 仍在 dialog 內
- [x] C-03 刪專案議題確認後列表少一筆
- [x] C-04 刪專案按鈕只在內容 tab；確認後回清單

## D. 跳轉

- [x] D-01 首頁／月曆點專案議題 → 自動在議題 tab、列高亮、dialog 打開
- [x] D-02 首頁點專案自己的追蹤（無 item）→ 內容 tab 並高亮該筆
- [x] D-03 `?item=` 不存在 → 橫幅「找不到該專案議題」，專案仍可看

## E. 視覺

- [x] E-01 tab 為圓角 chip，與成員頁同類，不是高飽和底線 tab
- [x] E-02 奶油白底、霧藍、棕灰文字、大圓角淺陰影
