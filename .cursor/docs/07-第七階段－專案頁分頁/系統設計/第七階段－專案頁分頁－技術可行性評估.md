# 第七階段－專案頁分頁－技術可行性評估

**角色：** RD Tech Spike  
**日期：** 2026-09-04  
**依據：** [功能規格書](../需求規劃/第七階段－專案頁分頁－功能規格書.md) v1.0  

| 項目 | 結論 | 說明 |
|------|------|------|
| 分頁元件 | 可行 | 重用 `MembersPage` 的 `.filters.member-tabs` + `.chip`／`.chip.active`，不必新套件。 |
| 狀態 | 可行 | `ProjectPage` 加 `tab`：`content`／`items`。表單 state 不因切換而重設。 |
| 新增專案 | 可行 | `isNew` 時不渲染 tab，維持單一 `<form>`。 |
| 跳轉 | 可行 | 既有 `useSearchParams`：`item` 有值時 `setTab("items")` 再走現有 `openEdit`／高亮；僅 `trackTodo` 時 tab 維持 `content`，`TrackTodoList` 的 `highlightId` 邏輯不變。 |
| API／DB | 不需改 | 仍 `GET/PUT /projects/{id}` 與既有項次、追蹤路徑。 |

規格 Spike 狀態：**已確認可行**。不擋 DA／RD。
