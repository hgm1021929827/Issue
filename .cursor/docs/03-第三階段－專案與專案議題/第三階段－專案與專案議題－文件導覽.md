# 第三階段－專案與專案議題－文件導覽

| 項目 | 說明 |
|---|---|
| 階段目標 | 手動維護專案與專案議題 |
| 需求類型 | ① Web 應用（含 UI／API，將有 Database） |
| 技術棧 | 沿用第一階段：React（Vite）、ASP.NET Core 9、MySQL |
| 狀態 | 已結束（2026-09-02 測試完成） |
| 與第一階段關係 | 不覆寫第一階段正式文件；分類、正式議題、TODO、首頁契約維持第一階段 |
| 與第二階段關係 | 新畫面與元件必須對齊 [視覺設計規格書](../02-第二階段－粉彩視覺風格/需求規劃/第二階段－粉彩視覺風格－視覺設計規格書.md) |
| 原始需求 | [個人工作追蹤網頁需求修正與新增內容.pdf](../../../docs/個人工作追蹤網頁需求修正與新增內容.pdf)（不複製、不改該檔） |
