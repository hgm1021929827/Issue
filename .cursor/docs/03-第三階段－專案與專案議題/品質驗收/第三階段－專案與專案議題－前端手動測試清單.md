# 第三階段－專案與專案議題－前端手動測試清單

**角色：** QA（清單供人工點擊；本文件不代替你實際操作）  
**狀態：** 使用者於 2026-09-02 確認完成

前置：後端 `http://localhost:5080`、前端 `http://localhost:5173`。新畫面應為奶油白底、霧藍主色、棕灰文字、大圓角淺陰影。

1. 導覽出現「專案」。點進去為專案清單，不是首頁議題清單。空庫或無資料時顯示尚無專案與「立即新增」。
2. 「新增專案」：代號、名稱必填；大分類預設為「議題分類」→ 否則「預約」→ 否則第一筆；小分類可空白（空白時標籤顯示大分類名稱）。填預計開始日與預計完成日後儲存，應進入該專案詳情。
3. 代號重複（含只差大小寫）應出現錯誤橫幅，不可建出第二筆。
4. 開始日晚於完成日不可存。
5. 專案清單可依大分類篩選；卡片可見代號、名稱、小分類色、項次筆數。點列進詳情。
6. 詳情可改名稱、說明、小分類後儲存；色標隨小分類更新。無獨立「完成」核取方塊。
7. 「新增專案議題」：以 `dialog` 開啟。手填項次與標題必填。同一專案項次不可重複；可再開另一專案用相同項次。儲存或取消後對話框關閉，列表更新。
8. 點列表列應以 `dialog` 開啟編輯；取消不改資料。刪一筆專案議題有確認，刪後列表少一筆，專案本身仍在。
9. 「刪除專案」：`dialog` 文案含代號或名稱，並寫「將一併刪除 N 筆專案議題」。取消不刪。確認後回清單，該專案與底下議題皆無。
10. 首頁「議題清單」仍只有正式議題，不出現專案列。
11. 月曆「到期日」：有預計完成日的專案顯示代號、專案議題顯示「代號 項次」；圖示與 `aria-label` 可區分三種來源。預計開始日不出現標記。
12. 「預計項目」視角：專案與專案議題標記不可拖、沒有移出鈕；正式議題排入／移出仍可用。
13. 點專案標記進 `/projects/{id}`。點專案議題標記進 `/projects/{id}?item=`，該列高亮並以 `dialog` 打開編輯。將 `item` 改成不存在的 id 再開，專案仍在，橫幅「找不到該專案議題」。
14. 分類設定：刪已被專案或專案議題使用的大／小分類，應失敗並看到使用中筆數（含專案種類）。只被正式議題使用時行為與第一階段相同。
15. 窄螢幕：專案清單與詳情仍可捲動操作；月曆同日多標記可在格內捲動。
