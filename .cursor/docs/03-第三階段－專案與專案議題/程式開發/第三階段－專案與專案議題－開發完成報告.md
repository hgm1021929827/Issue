## 本次完成功能

- 專案 CRUD、清單篩選、詳情
- 專案議題 CRUD（隸屬專案；項次同專案唯一；不可改掛）
- 刪專案確認後連同專案議題刪除
- 大小分類刪除擴大檢查（正式議題／專案／專案議題）
- 行事曆到期日視角加上專案、專案議題；依 `source` 跳轉；預計項目不含專案
- 點專案議題標記進入 `/projects/{id}?item=` 高亮並打開編輯
- 導覽「專案」；畫面沿用粉彩 token 與 `dialog`

## 新增資料表

- `project`
- `project_issue`（`ON DELETE CASCADE` 所屬專案）

既有庫於啟動時 `DbSeeder.EnsureSchema` 以 `CREATE TABLE IF NOT EXISTS` 補建（`EnsureCreated` 不會幫舊庫加表）。

## API

| 方法 | 路徑 |
|------|------|
| GET／POST | `/projects` |
| GET／PUT／DELETE | `/projects/{id}` |
| GET／POST | `/projects/{projectId}/items` |
| PUT／DELETE | `/projects/{projectId}/items/{id}` |
| GET | `/issues/calendar`（增量 `source`／`label`／`projectId`） |
| DELETE | `/majorCategories/{id}`、`/subCategories/{id}`（409 文案含專案筆數） |
