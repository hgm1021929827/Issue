# 一、專案介紹

預約連線用來記「哪一天要跟哪個客戶窗口連線、連線時處理哪些工作」。與把議題大分類改成「預約」無關。專案主檔補一般 TODO，才能把「專案底下的一般 TODO」掛進處理事項。

# 二、專案目標

1. 維護預約連線：客戶公司、窗口、狀態、日期、處理事項。
2. 同一客戶若已有未來未結束預約，可再新增或把事項加入既有。
3. 獨立清單頁與跳轉；有日期者出現在首頁行事曆。
4. 專案「內容」tab 有與議題相同的多層待辦。

# 三、產品定位

| 欄位 | 說明 |
|------|------|
| **本期範圍** | 預約 CRUD／合併／清單／行事曆；專案主檔待辦樹 |
| **不在範圍** | 專案議題待辦；工作項次當處理事項；追蹤 TODO 當處理事項；加簽；登入 |

# 四、功能需求

### AP-F01：專案主檔待辦

| 項目 | 需求 |
|------|------|
| 功能目的 | 專案可拆一般 TODO，供預約處理事項掛載 |
| 優先級 | Must |
| 是否本輪 MVP | 是 |
| 使用流程 | 專案詳情「內容」tab，追蹤 TODO 旁出現「待辦」。規則對齊議題 WT-F04／F05：多層、同層拖曳、父項自動完成、新增填標題＋內容。 |
| 功能限制 | 不可拖曳改掛父項。不上行事曆。專案議題無待辦。 |
| 驗收條件 | 可建至少三層；刪專案連刪專案待辦；匯入不覆蓋待辦。 |

### AP-F02：預約連線欄位與入口

| 項目 | 需求 |
|------|------|
| 功能目的 | 從議題／專案／清單新增或編輯一筆預約 |
| 優先級 | Must |
| 是否本輪 MVP | 是 |
| 使用流程 | 議題詳情、專案「內容」tab「新增預約連線」進入 `/appointments/new?issue=` 或 `?project=`。導覽「預約連線」進清單，可新增。編輯 `/appointments/{id}`。客戶公司：從工作帶出唯讀，清單新增必選。窗口只列該公司。未設廠商不可新增。狀態＝大分類「預約」小分類；畫面名稱用小分類、顏色用大分類。預設「已發信」否則第一筆。找不到「預約」擋下。日期可空。 |
| 功能限制 | 窗口必須屬於該公司。改公司清空窗口。 |
| 驗收條件 | 從議題新增後清單看得到該議題為處理事項；窗口下拉不含別家窗口。 |

### AP-F03：連線處理事項

| 項目 | 需求 |
|------|------|
| 功能目的 | 一筆預約掛多筆要在連線時處理的工作 |
| 優先級 | Must |
| 是否本輪 MVP | 是 |
| 使用流程 | 可掛正式議題、專案、該二類底下一般 TODO。從議題／專案進入預設掛該筆，可移除再加。清單新增可空。同一目標不可重複。 |
| 功能限制 | 需要追蹤的 TODO、專案議題、工作項次及其待辦不可選。 |
| 驗收條件 | 可加議題 TODO 與專案 TODO；加工作項次待辦被擋。 |

### AP-F04：既有未來預約

| 項目 | 需求 |
|------|------|
| 功能目的 | 避免同一客戶被重複約未來連線，又允許合併事項 |
| 優先級 | Must |
| 是否本輪 MVP | 是 |
| 使用流程 | 新增時若該客戶有未結束且日期晚於今天的預約，dialog 列出摘要（客戶、窗口、日期、狀態、目前處理事項）。選再新增，或選一筆加入事項（不新建）。 |
| 功能限制 | 無日期不觸發。結束＝狀態名稱「連線完成」或「連線取消」（trim、忽略大小寫）。空白狀態未結束。今天不算未來。 |
| 驗收條件 | 未來未結束會提示；加入既有後舊預約事項增加、不另建列。 |

### AP-F05：清單與跳轉

| 項目 | 需求 |
|------|------|
| 功能目的 | 一次查看所有預約 |
| 優先級 | Must |
| 是否本輪 MVP | 是 |
| 使用流程 | 清單顯示客戶、窗口、狀態、處理事項摘要、日期。議題跳議題詳情；專案跳專案詳情；TODO 跳所屬工作並 `?todo=` 定位。TODO 可展開內容與子 TODO。可刪預約。 |
| 驗收條件 | 無日期仍在清單；跳轉落點正確。 |

### AP-F06：行事曆

| 項目 | 需求 |
|------|------|
| 功能目的 | 有日期的預約出現在首頁月曆 |
| 優先級 | Must |
| 是否本輪 MVP | 是 |
| 使用流程 | 新視角「預約連線」。格子顯示客戶名稱與預約狀態。點選進編輯頁。改日期同步。無日期不上曆。 |
| 驗收條件 | 填日期當月看得到；清空日期後消失。 |

### AP-F07：刪除檢查

| 項目 | 需求 |
|------|------|
| 功能目的 | 使用中主檔不可刪 |
| 優先級 | Must |
| 是否本輪 MVP | 是 |
| 使用流程 | 刪公司／窗口／被預約當狀態的小分類：409 含預約筆數。刪議題／專案／待辦：拿掉對應處理事項，預約留下。刪預約連刪其處理事項。 |
| 驗收條件 | 使用中窗口不可刪；刪議題後預約仍在且該議題事項消失。 |

# 五、資料欄位

預約：客戶公司、客戶窗口、狀態小分類（可空）、預約日期（可空）。處理事項：恰一歸屬（議題／專案／待辦）。待辦列：既有欄位；歸屬恰一為議題、專案或工作項次。

# 六、未來規劃

專案議題待辦；工作項次納入處理事項；加簽恢復。
