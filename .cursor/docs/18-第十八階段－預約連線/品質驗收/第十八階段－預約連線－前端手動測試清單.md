# 第十八階段－預約連線－前端手動測試清單

請在本機前後端啟動後勾選。畫面依第二階段粉彩規格。

## 專案待辦

- [x] 專案「內容」tab 有待辦樹，可新增根項（標題＋內容）與子步驟
- [x] 勾選最後一筆未完成子項後父項自動完成；取消子項不取消父項
- [x] 同層可拖曳排序；不可拖到其他父項
- [x] 刪專案後該專案待辦消失

## 預約新增與編輯

- [x] 導覽有「預約連線」，清單可新增
- [x] 議題詳情「新增預約連線」帶入該議題與廠商（唯讀）
- [x] 專案內容 tab「新增預約連線」帶入該專案
- [x] 窗口下拉只有該公司窗口；換公司後窗口清空
- [x] 狀態為預約小分類，顏色為大分類色；預設已發信
- [x] 未設廠商的工作無法新增（有提示）
- [x] 可加正式議題、專案、其一般 TODO；看不到追蹤 TODO／工作項次待辦
- [x] 同一事項不可重複加入

## 未來預約合併

- [x] 同一客戶已有「明天」且狀態非連線完成／取消時，新增會跳出選擇
- [x] 再新增會多一筆
- [x] 加入既有後舊筆事項增加、清單不新增列
- [x] 無日期或狀態為連線完成／取消不提示

## 清單、跳轉、行事曆、刪除

- [x] 清單顯示客戶、窗口、狀態、摘要、日期
- [x] 議題／專案跳轉正確；TODO 進詳情並定位
- [x] TODO 可展開看內容與子項
- [x] 有日期出現在首頁月曆「預約連線」視角，文案為客戶＋狀態，點進去編輯
- [x] 清空日期後月曆不再顯示，清單仍在
- [x] 可刪預約
- [x] 刪使用中窗口／公司失敗並提到預約筆數
