# 第十八階段－預約連線－QA 測試案例

**依據：** [系統設計書](../系統設計/第十八階段－預約連線－系統設計書.md) v1.0  

| 案例 | 預期 |
|------|------|
| 01 專案內容待辦 | 內容 tab 有待辦；可新增標題＋內容 |
| 02 專案待辦三層與父項完成 | 與議題規則相同 |
| 03 刪專案 | 專案待辦一併消失 |
| 04 狀態來源 | 狀態下拉為「預約」小分類；預設已發信 |
| 05 無預約大分類 | 無法存狀態／提示找不到 |
| 06 從議題新增 | 公司唯讀；預設處理事項為該議題；窗口僅該公司 |
| 07 未設廠商 | 不可新增預約 |
| 08 處理事項種類 | 可掛議題、專案、其 TODO；工作項次待辦不可 |
| 09 重複事項 | 同一目標第二次 409 |
| 10 未來未結束合併 | dialog 可再新增或加入既有 |
| 11 無日期／已結束 | 不出現在 future |
| 12 清單 | 欄位齊；TODO 可展開；跳轉 `?todo=` |
| 13 行事曆 | 有日期顯示客戶＋狀態；清空後不上曆 |
| 14 刪窗口使用中 | 409 含預約筆數 |
| 15 刪議題 | 預約留下，該議題事項消失 |
| 16 刪預約 | 事項一併刪 |
| 17 視覺 | 粉彩；dialog；導覽「預約連線」 |
