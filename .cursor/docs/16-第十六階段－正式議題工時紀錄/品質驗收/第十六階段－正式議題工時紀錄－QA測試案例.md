# 第十六階段－正式議題工時紀錄－QA 測試案例

**依據：** [系統設計書](../系統設計/第十六階段－正式議題工時紀錄－系統設計書.md) v1.0  

| 案例 | 預期 |
|------|------|
| 01 載入既有議題 | 表單下、追蹤 TODO 上顯示「紀錄工時」；合計 0.00 |
| 02 新增工時 | 日期／時數／備註可存；列表出現；合計更新 |
| 03 同日再新增 | 409／「同一日已有工時」 |
| 04 編輯／刪除 | 可改日期時數備註；刪除後合計正確 |
| 05 時數驗證 | ≤0、>999.99、過多小數 → 400 |
| 06 新建議題頁 | 無工時區 |
| 07 刪議題 | 議題與工時皆刪；再查 hours 404 |
| 08 專案工時 | 工作項次／專案議題工時行為不變 |
| 09 視覺 | 奶油白／霧藍／大圓角，對齊專案工時卡 |
