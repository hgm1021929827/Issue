## 一、理念

工時仍單一表。正式議題與工作項次／專案議題並列為第三種歸屬。`hours_total` 查詢計算，不存欄。正式議題不加實際起迄欄。

主鍵／命名慣例不變。庫名 `issue_tracker`。

| work_hour | 加 `issue_id`；更新 CHECK；加唯一鍵與 FK |

## 三、work_hour（加欄）

| 欄位名稱 | 中文名稱 | 資料型態 | 驗證限制 | 是否允許 NULL | 預設值 | 說明 |
| -------- | -------- | -------- | -------- | ------------- | ------ | ---- |
| issue_id | 正式議題歸屬 | BIGINT | FK → issue | 是 | NULL | 與另外兩 FK 恰一有值 |

C#：`WorkHour.IssueId`；導航 `Issue`。

CHECK `ck_work_hour_target`（更新後）：

```
(project_work_item_id IS NOT NULL AND project_issue_id IS NULL AND issue_id IS NULL)
OR (project_work_item_id IS NULL AND project_issue_id IS NOT NULL AND issue_id IS NULL)
OR (project_work_item_id IS NULL AND project_issue_id IS NULL AND issue_id IS NOT NULL)
```

唯一鍵：`uk_work_hour_formal_issue`（`issue_id`, `work_date`）。

FK：`fk_work_hour_formal_issue` → `issue(issue_id)`；MySQL `ON DELETE CASCADE`；SQL Server 應用層刪議題前先刪工時。

既有 `uk_work_hour_item`／`uk_work_hour_issue`、`ck_work_hour_value` 不變。

## 四、遷移注意

既有列 `issue_id` 為 NULL。Seeder：加欄 → 加索引／FK → DROP 舊 CHECK → ADD 新 CHECK。新建表 DDL 直接含三 FK。
