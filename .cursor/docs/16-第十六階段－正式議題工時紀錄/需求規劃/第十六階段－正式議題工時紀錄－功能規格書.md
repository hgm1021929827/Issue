# 第十六階段－正式議題工時紀錄－功能規格書

**角色：** PM  
**版本：** v1.0  
**日期：** 2026-09-13  
**需求類型：** ① Web 應用（Database Schema 增量＋API＋畫面）  
**來源：** 使用者「我要在議題中增加類似專案的工時紀錄」；範圍確認僅逐日工時 CRUD（方案 A）

### IH-F01

| 項目 | 需求 |
|------|------|
| 目的 | 在正式議題詳情紀錄每日工時，與專案工作項次／專案議題相同操作體驗 |
| 優先級 | Must |
| MVP | 是 |
| 流程 | 開啟既有議題 `/issues/:id`：表單下方、追蹤 TODO 上方出現「紀錄工時」。選日期、輸入時數、可選備註後新增；可編輯／刪除既有列；右上顯示合計。新建議題頁不顯示工時區。 |
| 限制 | 同一議題同一日最多一筆。時數須 > 0 且 ≤ 999.99、最多兩位小數。不做完成狀態、實際開始／結束日、Excel 備註解析、列表合計、行事曆／首頁工時。專案側工時行為不變。 |
| 驗收 | 可新增／改／刪；同日再新增提示衝突；合計正確；刪除議題後工時一併消失；粉彩視覺與專案工時區一致。 |

**本功能擴充 `work_hour`，新增可空 `issue_id`。**
