# 一～二

沿用 `issue_todo` 與 `/todos/{id}`，加工作項次承載，避免兩表 IDENTITY 撞號。`TodoTree` 新增表單加內容；工作項次用 `compact`。

# 三、流程

1. 開啟工作項次：`GET /projects/{projectId}/work-items/{id}/todos`。
2. 新增：`POST` 同路徑，body `{ parentId?, title, content? }`；父項必須同承載。
3. 改／完成／排序／刪：既有 `/todos/{id}`，回傳該承載整棵樹。
4. 父項自動完成、同層 reorder 語意不變。
5. 刪項次／專案／匯入刪列：先刪 `issue_todo` 再刪項次。

# 四、API

| 方法 | 路徑 | Body | `data` |
|------|------|------|--------|
| GET | `/projects/{projectId}/work-items/{id}/todos` | — | `TodoNode[]` |
| POST | 同上 | `{ parentId?, title, content? }` | `TodoNode[]` |
| PUT | `/todos/{id}` | `{ title, content? }` | `TodoNode[]` |
| PUT | `/todos/{id}/complete` | `{ isCompleted }` | `TodoNode[]` |
| PUT | `/todos/{id}/reorder` | `{ parentId, orderedIds }` | `TodoNode[]` |
| DELETE | `/todos/{id}` | — | `TodoNode[]` |

`TodoNode`：`{ id, issueId, projectWorkItemId, parentId, isCompleted, title, content, sortOrder, children }`。`issueId` 與 `projectWorkItemId` 恰一有值。

議題 `GET/POST /issues/{id}/todos` 不變。

錯誤：找不到工作／TODO → 404；標題空白 → 400；父項不同承載 → 400；跨層排序 → 409。
