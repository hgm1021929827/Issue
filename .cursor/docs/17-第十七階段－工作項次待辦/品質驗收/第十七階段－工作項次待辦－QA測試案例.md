# 第十七階段－工作項次待辦－QA 測試案例

**依據：** [系統設計書](../系統設計/第十七階段－工作項次待辦－系統設計書.md) v1.0  

| 案例 | 預期 |
|------|------|
| 01 開啟工作項次 | 右側有「待辦」；空樹可新增 |
| 02 新增根項含內容 | 標題＋內容一次寫入；列表／詳情看得到內容 |
| 03 只填標題 | 可新增；內容為空 |
| 04 子步驟三層 | 可建根－子－孫；縮排正確 |
| 05 父項自動完成 | 勾最後一筆子項後父項完成；取消子項不取消父項 |
| 06 同層拖曳 | 順序保存；拖到其他父項不改歸屬 |
| 07 標題空白 | 不可存 |
| 08 跨承載父項 | POST 帶議題 TODO id 當父 → 400 |
| 09 刪工作項次 | 待辦一併消失 |
| 10 刪專案 | 其項次待辦一併消失 |
| 11 匯入不覆蓋 | 再次匯入項次後待辦仍在 |
| 12 議題待辦新增 | 議題頁新增也可同時填內容；既有完成／拖曳仍可用 |
| 13 視覺 | 工作項次單欄 compact；粉彩 token |
