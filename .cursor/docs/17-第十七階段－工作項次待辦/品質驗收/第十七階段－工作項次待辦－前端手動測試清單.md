# 第十七階段－工作項次待辦－前端手動測試清單

> 使用者已勾選完成（2026-09-17）。

- [x] 專案工作項次右側有「待辦」，可新增根項（標題＋內容一次送出）
- [x] 只填標題、內容留空仍可新增
- [x] 可新增子步驟，至少三層，同層可拖曳排序
- [x] 勾選最後一筆子項後父項自動完成；取消子項不會取消父項
- [x] 工作項次以鉛筆開啟就地編輯、叉號關閉，可改標題與內容並儲存
- [x] 父項可收起／展開子步驟；「隱藏已完成」可切換
- [x] 刪除待辦會連刪子步驟；刪工作項次後待辦消失
- [x] 議題詳情新增待辦也可同時填標題與內容
- [x] 工作項次待辦為單欄，不把議題頁雙欄硬塞進右欄
- [x] 外觀對齊粉彩（奶油白／霧藍／大圓角）
