# 第一階段－個人工作追蹤－QA測試案例

**角色：** QA  
**類型：** 需求類型 ① 功能驗收  
**依據：** 系統設計書、資料庫設計書、需求補充文件  
**狀態：** 2026-09-02 結案（見測試報告）

| 編號 | 案例 | 預期 |
|------|------|------|
| TC-01 | GET `/majorCategories` | 200；空庫種子為預約、議題分類（名稱可之後被改） |
| TC-02 | 同大分類新增重複小分類名稱 | 409 |
| TC-03 | 跨大分類同名小分類 | 成功 |
| TC-04 | 議題使用中的小分類刪除 | 409，訊息含筆數 |
| TC-05 | 新增議題無標題或無編號 | 400；編號重複 409 |
| TC-06 | 新增大分類重名 | 409 |
| TC-07 | 三層 TODO，勾選最後一筆孫項 | 子與父自動完成 |
| TC-08 | 取消已完成子項 | 祖先仍完成 |
| TC-09 | 手動完成父項 | 子項不變 |
| TC-10 | reorder 帶不同 parentId | 409 |
| TC-11 | 刪議題 | TODO 一併消失 |
| TC-12 | 有 dueDate 的議題 | 出現在到期日視角對應月曆格 |
| TC-13 | 無 dueDate | 不出現在到期日視角 |
| TC-14 | 單元測試 | `dotnet test` 全部通過 |
| TC-15 | 刪使用中的大分類 | 409，訊息含筆數 |
| TC-16 | 刪最後一個大分類 | 409 至少需保留一個 |
