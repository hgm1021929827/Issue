# 二、整體風格

整體採用**柔和、低飽和的粉彩風格（Soft / Muted Pastel）**。

視覺感受可參考三麗鷗風格所帶來的柔和、療癒與親切感，但不要過度卡通化或幼兒化，仍須保留工作管理系統應有的清楚與實用性。

整體關鍵字：

**柔和、療癒、低飽和、圓潤、清爽、溫暖、可愛但不幼稚、適合長時間使用。**

第一印象必須是：

**奶油白底＋柔和淺藍為主的粉彩工作管理介面**

而不是五顏六色的兒童風格頁面。

# 四、色彩計畫

## 4.1 背景

- 主要頁面背景必須是帶溫度的奶油白 `#FFF9F2`。
- 禁止以純白作為整個頁面的唯一背景。
- 部分內容區（行事曆、待辦詳情欄）可搭配非常淡的藍白色 `--bg-soft`，增加層次。
- 頁面可有極淡霧藍光暈作為背景層，輔助粉彩不得搶過主色（粉紅光暈須極弱）。

## 4.2 主色

主色採用**低飽和淺藍色／霧藍色**（`--accent` 系）。

不要使用鮮豔天空藍或高飽和藍色。

淺藍主要應用於：

- 主要操作按鈕
- 選取狀態
- 導覽列目前頁
- 主要資訊卡片的 Hover／Focus
- 頁面重要視覺元素（標題旁圖示可染 `--accent-ink`）

整體應讓使用者第一眼感受到這是一個「**淺藍色系的系統**」。

主按鈕文字使用 `--ink-deep`，不要為了對比改回純白大面積按鈕字（霧藍底偏淺，白字對比不足）。

## 4.3 文字

- 主要文字不要使用純黑色。
- 主要文字：`--ink` `#7A5C41`。
- 次要文字：`--muted` 或 `--muted-blue`。
- 藉由「奶油白背景＋霧藍主色＋棕灰文字」營造柔和且具有溫度的視覺效果。

## 4.4 粉彩輔助色（語意固定）

不同資訊、狀態與功能使用不同的低飽和粉彩，**用途必須一致**，禁止為裝飾而隨機上色。

| 語意 | 色系 | Token／作法 | 畫面例子 |
|------|------|-------------|----------|
| 主要資訊、一般、系統主操作 | 粉藍／霧藍 | `--accent*` | 儲存、導覽選取、今日、清單 Hover |
| 完成、正常、成功 | 粉綠 | `--pastel-green` | TODO 已完成核取、已完成篩選 Chip |
| 待處理、提醒、即將到期 | 粉橘／奶油黃 | `--pastel-peach` | 預計日 0–3 天內 |
| 重要、需要注意、過期 | 粉紅 | `--pastel-pink`、`--danger*` | 過期預計日、錯誤橫幅、刪除 |
| 統計、特殊、次要分類 | 粉紫 | `--pastel-purple` | 後續統計卡；現況少用 |

所有顏色皆須保持**低飽和、低刺激感**。

避免使用：

- 螢光色
- 高飽和原色
- 過亮天空藍
- 大面積鮮紅
- 強烈黑白對比

### 分類色票（小分類備選色）

整體 UI 仍維持奶油白底、棕色文字、霧藍主色與大圓角；**僅色票本身**改為一組統一的低飽和粉彩色盤。顏色須柔和但具足夠辨識度，**不要過度淡化**；避免高飽和、螢光或過度蒼白。

固定 10 色（`GET /colorPresets`；由冷至暖、相近色系排列，勿隨機排序）：

| 順序 | 名稱 | Hex |
|------|------|-----|
| 1 | 粉藍 | `#A9D6E8` |
| 2 | 霧藍 | `#91BFD5` |
| 3 | 灰紫 | `#B8B4CF` |
| 4 | 薰衣草紫 | `#C7BAD9` |
| 5 | 薄荷綠 | `#A8D8CF` |
| 6 | 鼠尾草綠 | `#B7CDB1` |
| 7 | 奶油黃 | `#E8D5A9` |
| 8 | 杏桃橘 | `#EBC5A5` |
| 9 | 霧粉紅 | `#DFB6BE` |
| 10 | 奶茶色 | `#D6C1A5` |

空白小分類／無法辨識時的預設色為**霧藍** `#91BFD5`（取代舊 `#8FA8C8`）。啟動時 seeder 會把庫內第一階段舊備選色對應到上表最接近色。

畫面上**禁止**把備選色直接當大面積高對比色塊（例如整顆按鈕白字＋高飽和底）。

規定：

1. 以 CSS 變數傳入實際 hex（如 `--chip-color`、`--select-color`、`--mark-color`）。
2. 清單／Chip／Tag 底可用 `color-mix` 混奶油／白再當底；**色票挑選器（`.color-dot`）**須接近原色以利辨識，勿過度混白。
3. 文字維持 `--ink`／`--ink-deep`。
4. 清單／分類卡片左側可用 **4px 圓角飾條**顯示原色，方便辨識狀態。
5. **選中色票**：禁止深棕色粗外框。改以輕微放大（約 `scale(1.18)`）、白色內圈邊框與柔和陰影表示選取。

# 五、卡片風格

頁面主要資訊以卡片形式呈現。

- 超大圓角：`--radius-card`（`2rem`）。
- 避免明顯深色邊框。
- 採用：**淡色背景＋同色系淺邊框＋極淡陰影**。
- 奶油向卡片用 `--paper`＋`--line`＋`--shadow`。
- 藍白向卡片（行事曆、分類卡層次）用 `--bg-soft`＋`--line-blue`＋`--shadow-blue`。
- 重要卡片左側可加一條細長粉彩飾條，用來快速辨識資訊類型或狀態。

---

# 六、陰影

- 避免厚重灰黑陰影。
- 使用非常輕微、柔和的陰影（視覺上接近 `shadow-sm`）。
- 陰影可稍微帶卡片本身色調（奶油棕或霧藍），讓卡片有輕微浮起即可。
- 不要產生明顯立體或懸浮效果。

---

# 七、按鈕與操作元件

按鈕、輸入框、下拉選單、Tag、Chip 皆採用圓潤設計。

| 種類 | 視覺 |
|------|------|
| 主要按鈕 `.btn` | 霧藍 `--accent`，Hover 僅改 `--accent-deep` |
| 次要按鈕 | 奶油白／淺藍白／淺灰藍；Hover 稍微加深 |
| 危險按鈕 `.btn.danger` | 柔和粉紅／粉紅灰，禁止高飽和鮮紅 |
| Chip | 未選：`--chip-bg`；選取：把分類色與白混合，文字仍為棕灰 |
| Tag | 混色淡底＋淺邊，不用白字實心色塊 |
| 輸入／textarea | 淺邊、圓角、Focus 時霧藍光暈 |
| 下拉（含彩色大分類） | 同 §4.4 混色，展開選單為大圓角淺卡片 |
| 日期選擇 | **禁止原生瀏覽器日曆開窗**。一律使用 `AppDateField`：奶油／霧藍月曆卡、大圓角、今日霧藍、選取霧藍、底部「今天／清除」 |

Hover 時僅稍微加深顏色，不要產生強烈顏色變化。

# 八、導覽列

導覽列採用**簡潔的懸浮式設計**。

- 禁止傳統深色、厚重的側邊導覽列。
- 奶油白／淡藍白背景＋大圓角＋輕微霧藍陰影。
- 目前所在頁面：柔和淺藍色 `--accent-soft` 作為選取狀態。
- 整體應像一張輕微浮在頁面上的卡片（可 sticky）。
- 品牌名可搭配一枚克制的 Sparkles 圖示。
- 導覽項目使用 Lucide 線性圖示＋繁中標籤。

實作對照：`frontend/src/App.jsx` 的 `.topbar`。

# 九、表格、清單與行事曆

- 避免傳統大量格線的企業系統風格。
- 表頭／月曆週次：淡奶油、淡藍或藍白底；文字深棕灰。
- 資料列之間用非常淡的分隔線或留白區隔。
- Hover：極淡淺藍背景。
- 議題列為大圓角卡片，左側飾條＋柔化 Tag。
- 行事曆儲存格圓角、淡分隔；**今日**用霧藍底。標記同樣混色，不用高對比色條。
- 空月與有標記時行事曆寬度仍固定（延續第一階段 WT-F01）。

預計完成日語意（首頁清單）：

| 狀態 | 樣式 |
|------|------|
| 無日期 | `--muted` |
| 剩餘超過 3 天 | 一般次要文字 |
| 今天起 3 天內 | `.due.is-soon`（粉橘） |
| 已過期 | `.due.is-overdue`（粉紅） |

# 十、裝飾元素

可以適量加入：星星、火花、小圓點、Sparkles、柔和幾何圖形。Lucide 為主要圖標來源。

裝飾主要出現在：

- 頁面標題旁
- 統計卡片（後續若新增）
- Empty State
- 完成狀態
- 特殊提示（如待辦未選取時）

裝飾必須保持克制。

**工作內容與資訊仍然是頁面的主角，裝飾元素只負責增加親切感。**

禁止：吉祥物插畫鋪滿、大量閃爍動畫、每個儲存格都放星星。

共用標題元件：`frontend/src/components/PageTitle.jsx`。

# 十一、整體視覺比例

大致控制為：

**奶油白／中性色 50%　·　淺藍主色 30%　·　其他粉彩輔助色 20%**

因此即使使用粉紅、粉紫、粉綠、粉橘，整體第一印象仍應是奶油白底＋柔和淺藍為主。輔助色只出現在狀態、篩選選取、飾條與少量提示，不可變成頁面主色。

# 十三、後續開發檢查清單

開新畫面或改現有畫面時，RD 須自檢：

1. 頁面底是 `#FFF9F2`，不是純白鋪滿。
2. 主文字是 `#7A5C41` 系，不是 `#000`／`#111`。
3. 第一眼仍是霧藍系統，輔助粉彩有語意。
4. 卡片圓角為 `2rem` 級，邊框淺、陰影極淡。
5. 主按鈕霧藍；危險操作粉紅灰。
6. 導覽是懸浮淺色卡，不是深色側欄。
7. 清單／表沒有濃密格線。
8. 分類色為 §4.4 粉彩色盤；標籤可混白，色票選取為放大＋白內圈＋柔陰影（非深棕粗框）。
9. Lucide 圖示克制，不搶內容。
10. 未改 API、Schema、商業規則（備選色內容除外）。

QA 視覺回歸可依本清單抽樣：首頁、詳情、分類設定、Dialog、Empty State、小螢幕（`max-width: 860px` 單欄）。

# 十四、明確禁止

| 禁止 | 改為 |
|------|------|
| 純白整頁、純黑字 | 奶油白＋棕灰字 |
| 高飽和藍／天空藍頂欄 | 霧藍點綴的懸浮淺色導覽 |
| 深紅危險鈕 | `--danger` 粉紅灰 |
| 白字實心分類色塊 | 混色淡 Tag＋左側飾條 |
| 厚重黑影、立體浮卡 | `--shadow`／`--shadow-blue` |
| 為了可愛而彩虹化每個區塊 | 維持 50／30／20 比例 |
