# 第十三階段－正式議題 Excel 匯入－文件導覽

| 項目 | 說明 |
|---|---|
| 階段目標 | 從 `議題匯入範本.xls` 匯入正式議題、再次匯入差異、匯入結果頁 |
| 需求類型 | ① Web 應用（含 UI／API，將有 Database） |
| 技術棧 | 沿用第一階段：React（Vite）、ASP.NET Core 9、MySQL |
| 狀態 | 進行中（QA 測試結案，待勾前端清單） |
| 與前階段關係 | 不覆寫第一～十二階段正式文件；正式議題／成員／廠商沿用；本輪增量接上正式議題匯入 |
| 與第二階段關係 | 新畫面與元件必須對齊 [視覺設計規格書](../02-第二階段－粉彩視覺風格/需求規劃/第二階段－粉彩視覺風格－視覺設計規格書.md) |
| 與第十二階段關係 | 專案 `P-*.xlsx` 匯入已結束；本輪只處理正式議題範本，不得把專案 Excel 規格直接套用 |
| 實務對照 | [議題匯入範本.xls](../../../Template/議題匯入範本.xls) |

本階段範圍只要正式議題 Excel 匯入、再次匯入差異與結果頁。加簽、預約連線、臨時工作、登入、專案檔其他工作表不在本輪。範圍凍結見 [階段開立紀錄](流程管理/第十三階段－正式議題 Excel 匯入－階段開立紀錄.md)。
