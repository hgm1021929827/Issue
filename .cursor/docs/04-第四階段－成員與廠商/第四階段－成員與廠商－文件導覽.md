# 第四階段－成員與廠商－文件導覽

| 項目 | 說明 |
|---|---|
| 階段目標 | 維護公司成員與客戶公司／窗口（含多筆聯絡），並讓工作可綁廠商與快捷新增 |
| 需求類型 | ① Web 應用（含 UI／API，將有 Database） |
| 技術棧 | 沿用第一階段：React（Vite）、ASP.NET Core 9、MySQL |
| 狀態 | 已結束（2026-09-05 使用者確認測試完成） |
| 與第一階段關係 | 不覆寫第一階段正式文件；成員仍是通訊錄，不是登入帳號 |
| 與第二階段關係 | 新畫面與元件必須對齊 [視覺設計規格書](../02-第二階段－粉彩視覺風格/需求規劃/第二階段－粉彩視覺風格－視覺設計規格書.md) |
| 與第三階段關係 | 不覆寫第三階段正式文件；本輪可增量讓專案（及討論勾選的議題）綁客戶公司 |
| 原始需求 | [個人工作追蹤網頁需求修正與新增內容.pdf](../../../docs/個人工作追蹤網頁需求修正與新增內容.pdf)（不複製、不改該檔）第九章、5.2、2.2、第十五章成員相關列 |

本階段不做 Excel 匯入、臨時工作、需要追蹤的 TODO、加簽、預約連線、登入。Excel 覆蓋前原稿見 [歷史資料](歷史資料/說明.md)。範圍凍結見 [階段開立紀錄](流程管理/第四階段－成員與廠商－階段開立紀錄.md)。
