- 公司成員 CRUD（中文名可重複；英文名必填）
- 客戶公司／窗口／聯絡資料 CRUD（公司名全系統唯一、窗口名同公司唯一、多筆聯絡）

- 專案／正式議題寫入必填客戶公司；表單有快捷新增廠商（只填公司名並自動選取）

## 新增資料表

- `company_member`
- `client_company`
- `client_contact`（`ON DELETE CASCADE` 所屬公司）
- `contact_channel`（`ON DELETE CASCADE` 所屬窗口）

既有表增量：`project.client_company_id`、`project.owner_member_id`、`issue.client_company_id`（可空 FK，`ON DELETE RESTRICT`）。舊庫於啟動時 `DbSeeder.EnsureSchema` 補建。不預設成員或公司。

## API

| 方法 | 路徑 |
|------|------|
| GET／POST | `/company-members` |
| PUT／DELETE | `/company-members/{id}` |
| GET | `/client-companies`、`/client-companies/tree` |
| POST | `/client-companies` |
| PUT／DELETE | `/client-companies/{id}` |
| POST／PUT／DELETE | `/client-companies/{companyId}/contacts[/{id}]` |
| POST／PUT／DELETE | `/client-companies/{companyId}/contacts/{id}/channels[/{channelId}]` |
| POST／PUT | `/projects`、`/issues`（寫入 `clientCompanyId` 必填；專案可選 `ownerMemberId`） |
