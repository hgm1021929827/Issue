# 第十一階段－首頁清單分頁－功能規格書

**角色：** PM  
**版本：** v1.0  
**日期：** 2026-09-04  
**需求類型：** ① Web 應用（UI only，無 Database）  
**來源：** 使用者「首頁的清單保留，裡面用tab區分專案(裡面要有專案議題)、正式議題、追蹤項目」

已跳過討論文件（F-01）。假設：第十階段獨立 `/issues` 頁保留。首頁再放回左側清單，與月曆並排。清單用三個 tab；專案 tab 每筆專案下列出其專案議題。API 與 Schema 不改。

### PV-F01

| 項目 | 需求 |
|------|------|
| 目的 | 首頁一眼可切換看專案、正式議題、追蹤項目 |
| 優先級 | Must |
| MVP | 是 |
| 流程 | 左側「工作清單」三 tab：專案、正式議題、追蹤項目。專案列下方嵌套專案議題。正式議題可拖／點排入月曆預計項目。追蹤列點進去跳轉。 |
| 限制 | 不改 `/issues` 獨立列表。不改寫入規則。專案議題列仍不顯示客戶公司。 |
| 驗收 | 三 tab 可切；專案下看得到專案議題；正式議題可排月曆；追蹤可跳轉。 |

**本功能無 Database 持久化，第七章 Database 項目 N/A。**
